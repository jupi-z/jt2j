# Prototype artwork

The `abstract-*.svg` compositions are extracted unchanged from the standalone
`artwork()` function in `docs/reference/JT2J_Prestige_Prototype.html`, for both
its original dark and light palettes. Names map to `home`, `HYG`, `SEC`, `LOG`,
`BIZ`, `TRV`, and the fallback commitment composition respectively. IDs live
inside separate SVG image documents, so instances cannot collide.

These are decorative illustrations from the approved visual reference. They are
not the official JT2J logo, photographs, partner logos, or approved factual claims.
No substitute brand assets have been invented. The official-logo slot remains
the prototype's temporary text signature until an approved asset is supplied.
